# Supplier Risk Intelligence

A synthetic supplier risk analytics project demonstrating data integration,
predictive modeling, model validation, explainability, and interactive
decision support using R, Shiny, Plotly, and SQL.

## Project Objective

This project will predict the probability that an open purchase-order line
will arrive more than 7 calendar days after its promised delivery date.

The predicted probability will be combined with operational impact factors,
including inventory coverage, material criticality, expected demand, order
value, and sourcing alternatives, to prioritize purchase orders for
mitigation.

## Planned Capabilities

- Generate reproducible synthetic supplier and procurement data
- Validate and integrate multiple supply chain datasets
- Engineer time-aware supplier performance features
- Compare logistic regression and XGBoost models
- Evaluate performance using out-of-time validation
- Explain global and individual predictions
- Prioritize risks using probability and business impact
- Present results through an interactive Shiny application
- Explore a Snowflake data workflow if time permits

## Data Statement

This project will use entirely synthetic data created for demonstration.

The project will not contain data, code, business rules, or proprietary
information from any employer, client, or prospective employer.
